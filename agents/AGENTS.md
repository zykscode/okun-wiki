# AGENTS.md

This directory contains the configuration and identity files for different agents.
Each subdirectory represents a unique agent that can be spawned.

To create a new agent:
1. Create a new subdirectory (e.g., `agents/new-agent-name`).
2. Populate it with its own `IDENTITY.md` and `SOUL.md`.
3. Optionally add agent-specific `TOOLS.md` or other configuration.
